# Start here

## Setup (about 5 minutes)

1. Unzip this folder somewhere you'll keep it, like `Documents/writers-room`.
2. Get an Anthropic API key at console.anthropic.com (you'll paste it in when Claude Code asks).
3. Open a terminal in this folder and run `claude` to start Claude Code.

## Session 1: paste this prompt

```
Read START_HERE.md, CLAUDE.md, SPEC.md and DECISIONS.md.

Don't write any code yet. First:
1. Walk me through the open questions in DECISIONS.md one at a time,
   with your recommendation for each, and record my answers there.
2. Then propose the tech stack, the data model (notes, spaces, books,
   provenance), and a step-by-step plan for Milestone 1 only
   (capture, transcription, Inbox).
3. Tell me how I'll run and test it on my phone.

Wait for my go-ahead before building.
```

## After that

- Say "go" to start Milestone 1. Claude Code will stop when it's done and show you how to try it.
- Test it for real (a drive, a few voice notes). Tell it what felt off.
- Start the next milestone only when the last one feels good.
- If Claude Code ever drifts (writing prose, adding features you didn't ask for), say: "Re-read CLAUDE.md."

## For the portfolio

Keep DECISIONS.md updated as you go. At the end, it plus SPEC.md, your evaluation results and a 2-minute demo video make the case study.
